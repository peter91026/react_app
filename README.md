# 臺北公共藝術推廣打卡微服務

此專案為「2024臺北秋季程式設計節 城市通微服務大黑客松」晉級複賽之作品。

## 專案簡介
本微服務以台北市公共藝術裝置為主題，結合政府公開資料與台北通APP。使用者登入後，可透過GPS定位查看周遭的公共藝術，並透過打卡功能深入探索藝術品資訊。

## 開發技術
* **前端**: 採用 React 進行網頁介面開發與設計。
* **後端**: 使用 Python 與 Flask 框架開發 API。
* **資料庫**: 採用 Firebase (NoSQL) 處理大量且不同類型的資料集。

## 核心功能
1. 結合台北通APP虛擬機運行
2. 台北市公共藝術GPS地圖顯示
3. 裝置藝術詳細資訊與打卡紀錄區
